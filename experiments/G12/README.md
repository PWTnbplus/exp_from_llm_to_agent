# G12 — Mechanism applicability and failure boundary

G12 probes conditions under which the mechanism weakens, fails or reverses. Negative and null signals are retained as evidence and are not relabelled as implementation errors.

```bash
python experiments/G12/run.py
python experiments/G12/evaluate.py
python experiments/G12/reproduce.py --resume
```

The public wrapper is offline engineering-only; additional independent blocks are required for robust inference.
