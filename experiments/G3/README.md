# G3 — Fixed iteration and reflection baseline

G3 tests a pre-defined reflection/iteration workflow without adaptive Agent tool choice. It provides the strong fixed-process baseline for G4.

```bash
python experiments/G3/run.py
python experiments/G3/evaluate.py
python experiments/G3/reproduce.py --resume
```

The public wrapper creates only labelled offline smoke output. It does not claim a scientific result.
