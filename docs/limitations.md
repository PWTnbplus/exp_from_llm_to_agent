# Limitations

NewtonBench is public, so pretraining or benchmark exposure cannot be ruled out even though its law variants use metaphysical shifts. The experiment measures the value of feedback-controlled experiment selection, not every possible Agent architecture.

The first implementation supports only direct-measurement tasks. Upstream dynamical systems require a separate measurement-information budget and have not been claimed as validated. A law recovered from a public simulator is not an original discovery of an unknown natural law. The Agent consumes more model calls by design, so cost and token efficiency must be reported beside VLDR. No classical adaptive-design baseline is included yet. Exact reproduction of real API text is not assumed; raw request metadata and response metadata must be archived.
